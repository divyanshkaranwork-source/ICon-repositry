# Changelog

## 1.0.0

- First release of Lumora.
- Five icon editions: **Aurora**, **Noir**, **Frost**, **Halo** and **Gilded** (Halo and Gilded ship dedicated light-theme sets).
- 388 file icons and 201 folder themes covering 1,200+ file names, 1,100+ extensions and 6,600+ folder names.
- Companion color themes: **Lumora Midnight** (dark) and **Lumora Daybreak** (light).
