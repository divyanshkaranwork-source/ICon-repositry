# Changelog

## 1.0.0

- First release.
- Three icon themes: **Folio Ink**, **Folio Graphite** and **Folio Primary**, each with dark and light sets.
- 388 file icons and 201 folder icons covering 1,200+ file names, 1,100+ extensions and 6,600+ folder names.
- Color themes: **Folio Dark** and **Folio Light**.
